# ResourceNest

A lightweight resource hub for students, developers, recent graduates, and job seekers.

ResourceNest brings learning guides, developer documentation, roadmaps, and career preparation into one browsable site.

## What it includes

- Search and category filters for the resource collection
- Goal-based prompts to help visitors choose a starting point
- Beginner-to-advanced roadmaps with progress saved in the current browser
- Resume, interview, and career preparation checklists
- A collection of developer documentation links
- A newsletter form shown as a front-end demo; it does not submit or store email addresses

## Built with

- HTML
- CSS
- JavaScript

The project is a static front end and does not require a backend or build step.

## Run locally

Clone the repository and open `index.html` in a modern browser:

```bash
git clone https://github.com/rahul2rcf-netizen/resourcenest.git
cd resourcenest
```

Alternatively, serve the directory with any static web server.

## Privacy and external links

Roadmap progress is described as being saved in the visitor's browser. The newsletter form is a visual demo and does not send data anywhere. Resource links open third-party sites, which have their own privacy practices.

## Status

ResourceNest is a work in progress. The project status section in the site describes the current and planned work.
